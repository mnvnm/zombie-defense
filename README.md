# 🧟 좀비 디펜스

좀비로 뒤덮인 도시에서 군인을 소환하고 합쳐 최강의 부대를 만들어 점점 강해지는 좀비를 막아내는 HTML5 게임입니다.

## 실행
`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. (설치 불필요)

## 조작
| 행동 | 폰 | PC |
|---|---|---|
| 유닛 소환 | 소환 버튼 터치 | 스페이스 / 클릭 |
| 유닛 합치기 | 같은 레벨 유닛 드래그 | 마우스 드래그 |
| 강화 창 | 강화 버튼 | U |
| 스킬 사용 | 오른쪽 스킬 버튼 | 1 (동결), 2 (골드 2배) |

## 특징
- 자동 사냥 + 같은 레벨 유닛 합성 (최대 Lv10)
- 유닛 레벨별 공격력·공격속도 강화
- 기지 강화: 골드 획득량, 철조망(좀비 감속), 자연회복
- 1회용 스킬: 모든 적 동결, 골드 2배
- 스테이지가 오를수록 강해지는 좀비, 군인이 모두 쓰러지면 게임 오버
